# AlphaRide passenger UX flow

The reference package was reviewed as an interaction and sizing guide. AlphaRide
keeps its own name, content, assets, neon-green identity, and business rules.

## End-to-end journey

1. Splash and session recovery
2. Phone number, consent, OTP, and profile completion
3. Location permission and map home
4. Pickup selection using current location, search, or map pin
5. Destination search with matching place suggestions
6. Route preview and responsive fare loading
7. Explicit Boda, Rickshaw, or car-class selection
8. Payment method and order confirmation
9. Driver matching with cancellation recovery
10. Assigned-driver identity, vehicle, plate, and call action
11. Pickup, waiting, and active-trip states
12. Completion, trusted fare, receipt, history, and feedback
13. Profile, wallet, appearance, safety, and support

## Shared visual contract

- 16 dp page and sheet padding
- 48 dp minimum interactive controls
- 56 dp primary actions
- 14 dp controls, 20 dp cards, and 24 dp modal sheets
- 48 by 5 dp sheet handle
- full light/dark parity with semantic surface, text, border, and status colors
- accessible labels and disabled/loading feedback for asynchronous actions
